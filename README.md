# astrbot_plugin_yjcbg

AstrBot 永劫无间藏宝阁查询插件。

## 安装

将 `astrbot_plugin_yjcbg` 目录放到 AstrBot 的 `data/plugins/` 下，然后在 WebUI 重载插件。

插件依赖：

```bash
pip install -r requirements.txt
```

## 命令

```text
/永劫藏宝阁 帮助
/永劫藏宝阁 搜索 关键词
/永劫藏宝阁 搜索 皮肤名 编号
/永劫藏宝阁 搜索 编号
/永劫藏宝阁 搜索 关键词 页码        # 末尾数字为翻页
/永劫藏宝阁 最低价 关键词          # 返回该皮肤当前最低价一件
/永劫藏宝阁 收藏 编号              # 收藏某个编号的商品
/永劫藏宝阁 收藏列表
/永劫藏宝阁 刷新收藏               # 更新收藏的最新价格
/永劫藏宝阁 取消收藏 编号
/永劫藏宝阁 提醒 皮肤名 编号
/永劫藏宝阁 提醒列表
/永劫藏宝阁 取消提醒 编号
/永劫藏宝阁 取消提醒                # 取消我的全部提醒
/永劫藏宝阁 诊断                    # 检查 Cookie / 接口连通 / 风控 / 配置
/藏宝阁 搜索 关键词
/永劫藏宝阁 验证码 123456   # 输入手机验证码完成风控验证
```

搜索可追加的选项（可同时组合）：

```text
价格升 / 价格降 / 收藏升 / 收藏降
公示期 / 在售期
1星格:2000-3000 2星格:100-200      # 星格区间，未指定星格不限制
价格:100-500                        # 价格区间（元），可写 价格:100- 或 价格:-500
```

示例：

```text
/永劫藏宝阁 搜索 胡桃
/藏宝阁 搜索 殷紫萍
/永劫藏宝阁 搜索 风之絮语
/永劫藏宝阁 搜索 风之絮语 Y002481   # 皮肤名 + 编号组合搜索
/永劫藏宝阁 搜索 胡桃 1星格:2000-3000 2星格:100-200   # 星格过滤
/永劫藏宝阁 搜索 胡桃 公示期 价格:100-500 价格升       # 多条件组合
/永劫藏宝阁 最低价 风之絮语
/永劫藏宝阁 收藏 Y002481
/永劫藏宝阁 提醒 风之絮语 Y002481   # 编号出现时提醒
```

提醒、收藏均按用户区分：每个用户的提醒/收藏独立保存，'提醒列表'/'收藏列表' 只显示自己的，'取消提醒'/'取消收藏' 只取消自己的（同一群内互不影响）。

## 功能

- 英雄名 / 皮肤名模糊搜索（覆盖英雄皮肤、武器皮肤、宝箱、礼包等全部类型），返回完整数据。
- 翻页查询（每页默认数量可配置）。
- 价格升序 / 降序、收藏升序 / 降序排序。
- 公示期 / 在售期过滤。
- 星格区间过滤（`1星格:2000-3000 2星格:100-200`，未指定星格不限制）。星格可能匹配多条，遍历完整列表后输出全部符合条件的结果。
- 价格区间过滤（`价格:100-500`，或 `价格:100-`、`价格:-500`）。与星格一样跨页全扫，准确优先。
- 搜索结果直接显示每条商品的星格数值（`variation_id`）。
- 编号模糊搜索（Y/S 等字母开头，如 `Y007`、`S001234`）。编号唯一，命中即停，追求速度。
- 皮肤名 + 编号组合搜索（分页抓取全部皮肤类型，在对应皮肤类型内模糊匹配编号，不遗漏任何变体）。
- 最低价查询（`/最低价 关键词`）：按价格升序扫描前几页，返回当前最便宜的一件。
- 收藏功能（`收藏 / 收藏列表 / 刷新收藏 / 取消收藏`）：收藏某个编号的商品形成快照，可刷新更新最新价格。
- 编号出现提醒（某皮肤某编号出现时主动提醒）。
- 诊断命令（`/诊断`）：检查 Cookie 有效性、接口连通与风控状态、配置与依赖。
- 显示卖家、洗练次数、收藏数。
- 触发手机风控（MOBILE_AUTH）时自动发送短信验证码，在消息端输入验证码完成验证后自动重试原查询。

## 配置

在 AstrBot WebUI 的插件配置里可以设置：

- `base_url`：默认 `https://yjwujian.cbg.163.com`
- `api_prefix`：默认 `/cgi/api`
- `cookie`：可选，部分查询可能需要登录态或风控 Cookie
- `timeout_seconds`：请求超时
- `max_results`：聊天里展示的结果数量（默认 5）
- `debug_raw_error`：开启后查询失败时返回更详细的接口错误信息
- `id_scan_pages`：编号搜索时每个皮肤类型扫描的页数（默认 0，表示遍历全部页搜索所有编号；>0 则只扫前 N 页）
- `list_order_by`：编号/组合搜索扫描列表时的排序参数（默认 `attrs.client_show_id ASC`）。必须带排序才能拿到完整在售列表，否则接口只返回推荐子集、会漏掉部分编号
- `id_scan_interval`：编号/星格搜索时每批请求之间的间隔秒数（默认 0.6，越大越不易触发风控）
- `batch_pages`：编号/星格搜索时每批查询的页数（默认 10），每批查询完会休息 `batch_interval` 秒
- `batch_interval`：每批之间等待秒数（默认 5），越大越不易触发风控但越慢
- `request_concurrency`：编号/星格搜索时并发抓取的页数（默认 2，越大越快但越易触发风控）
- `request_interval`：全局限流，所有藏宝阁请求之间的最小间隔（默认 1 秒，越大越不易触发风控但搜索越慢）
- `page_size`：每页请求数量（默认 50，调大如 100 可减少请求总数、更快；接口是否支持更大值需实测）
- `star_scan_pages`：星格区间搜索时每个皮肤类型扫描的页数（默认 0，表示遍历全部页搜索所有星格商品；>0 则只扫前 N 页）
- `lowest_price_scan_pages`：`/最低价` 查询时按价格升序扫描的前几页（默认 5）
- `reminder_interval`：编号提醒轮询间隔（默认 60 秒）
- `reminder_scan_pages`：提醒检查时每个皮肤类型扫描的前几页（默认 5，只扫最新上架，避免触发风控）

## 注意

- 藏宝阁对高频请求有风控（`CAPTCHA_AUTH` 安全验证、`MOBILE_AUTH` 手机短信验证）。`CAPTCHA_AUTH`/`SESSION_TIMEOUT` 会自动退避重试；触发 `MOBILE_AUTH` 时插件会自动发送短信验证码到绑定手机，你在消息端输入验证码（`/永劫藏宝阁 验证码 123456`）即可完成验证并自动重跑原查询。
- 编号模糊搜索（如 `Y007`、`S001234`）会遍历皮肤类型列表，速度较慢，请勿频繁连续调用。
- 星格 / 价格区间过滤会遍历完整列表，耗时较长，查询开始时会提示等待。
- 默认按价格升序对全部结果排序；翻页时排序在整个数据集上保持一致。

## 说明

藏宝阁没有公开稳定的第三方接口文档。本插件根据当前网页前端使用的接口做公共查询封装；如果网易后续调整接口、要求登录态或触发风控，可能需要更新配置或代码。
